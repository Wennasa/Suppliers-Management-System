# منظومة إدارة وتأهيل الموردين — الإصدار 2.0

ASP.NET Core 8 (Minimal APIs) + EF Core SQLite + واجهة أمامية عربية RTL (HTML/CSS/JS بدون اعتماديات).

## التشغيل
```bash
dotnet run
```
ثم افتح `http://localhost:5000` (أو المنفذ الظاهر في الطرفية). توثيق الـ API على `/swagger`.

عند أول تشغيل تُنشأ قاعدة البيانات `App_Data/suppliers.db` وتُعبأ بـ **30 مورداً تجريبياً** (أسماء افتراضية).
لإعادة التهيئة احذف مجلد `App_Data`.

## الشاشات
| الشاشة | الوصف |
|---|---|
| مطابقة قيمة المناقصة | إدخال القيمة والنشاط وتاريخ الإقفال ← ترشيح لحظي، أسباب الاستبعاد، خريطة الملاءة، مقارنة حتى 4 موردين، إصدار قائمة الدعوات |
| تعريف مورد جديد | معالج من 7 خطوات: البيانات الأساسية، السجل التجاري، مزاولة النشاط، السجل العقاري، عقد التأسيس والشركاء، المالية، الوثائق والمراجعة (مع حفظ مسودة تلقائي) |
| ملف المورد | بطاقات الوثائق القانونية وصلاحيتها، مسار الاعتماد المالي/القانوني، الوثائق المرفقة، سجل التعديلات |
| لوحة المؤشرات | المؤشرات، التصنيف، التوزيع حسب النشاط، تنبيهات الانتهاء، الملفات المعلقة |
| المناقصات | قوائم الدعوات مع تصدير CSV وطباعة/PDF |
| سجل التدقيق | سجل مُسلسل بسلسلة SHA-256 مع زر التحقق من السلامة |
| معايير التصنيف | حدود الفئات (أ/ب/ج)، نسبة BR-04، أيام التنبيه |

## قواعد الأهلية (محرك الترشيح)
- **BR-01** اكتمال: السجل التجاري، مزاولة النشاط، السجل العقاري، عقد التأسيس، رأس المال، النشاط.
- **BR-02** الحالة «نشط ومؤهل» + اعتماد مالي وقانوني.
- **LEG-1/2** سريان السجل التجاري وإذن المزاولة حتى تاريخ الإقفال.
- **BR-04** قيمة المناقصة ≤ 50% من رأس المال (قابلة للتعديل).
- مطابقة النشاط الرئيسي أو الفرعي.

## الأدوار (RBAC تجريبي)
يُختار الدور من أعلى الواجهة ويُرسل بالترويستين `X-Role` و`X-User`. هذا للمحاكاة فقط — يجب ربطه بنظام هوية حقيقي (Active Directory / JWT) قبل الإنتاج.
